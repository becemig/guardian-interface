# Learning and Memory

## Abstract

Memory comprises multiple systems including declarative memory for facts and events and procedural memory for skills and habits each with distinct neural substrates. Long-term potentiation in the hippocampus underlies declarative memory formation through NMDA receptor activation and synaptic strengthening. Memory consolidation involves the gradual transfer of memory from hippocampus to neocortex during sleep. Spaced repetition exploits the spacing effect to maximize long-term retention with minimum practice time. Shen governs the Heart's capacity for intentional learning and mental clarity while Yi the Spleen's intention governs focused directed thinking that drives encoding. Guardian Interface knowledge navigation is designed around spaced repetition and active retrieval principles.

## Memory Systems

- Declarative memory includes episodic memory for personal events and semantic memory for facts and concepts.
- Procedural memory governs motor skills, habits, and conditioned responses through basal ganglia and cerebellum.
- Working memory provides temporary active maintenance of information through prefrontal-parietal circuits.
- Emotional memory through the amygdala enhances consolidation of emotionally significant experiences.

## Long-Term Potentiation

- LTP is the synaptic strengthening mechanism underlying declarative memory formation in the hippocampus.
- NMDA receptor activation during coincident pre and postsynaptic activity drives LTP induction.
- AMPA receptor insertion at the synapse increases synaptic strength providing the substrate for memory.
- Practice and retrieval strengthen LTP through repeated NMDA activation consolidating long-term memories.

## Spaced Repetition

- The spacing effect shows that distributed practice produces better retention than massed practice.
- Optimal inter-repetition intervals expand as memory strengthens following the forgetting curve.
- Active retrieval during spaced repetition produces stronger memories than passive re-reading.
- Guardian Interface knowledge navigation supports spaced retrieval through repeated node visits across sessions.
