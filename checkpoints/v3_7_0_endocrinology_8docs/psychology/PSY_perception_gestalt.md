# Perception and Gestalt

## Abstract

Gestalt psychology describes the principles by which the perceptual system organizes sensory input into coherent wholes that exceed the sum of their parts. Figure-ground segregation is the fundamental perceptual operation distinguishing objects from their backgrounds. The Gestalt laws of proximity, similarity, continuity, closure, and common fate describe the organizing principles that create perceptual coherence from sensory noise. Top-down processing driven by expectation, context, and prior knowledge shapes bottom-up sensory input through predictive coding. Yi perception in TCM — the directed intention of the Spleen that discerns patterns and relationships — corresponds to the integrative perceptual function that creates meaningful wholes from sensory parts. Guardian Interface knowledge navigation is fundamentally a perceptual task of pattern recognition in an information space.

## Gestalt Laws

- Proximity groups elements that are close together into perceptual units.
- Similarity groups elements that share visual properties into perceptual units.
- Continuity perceives smooth continuous contours rather than abrupt changes in direction.
- Closure completes incomplete figures creating whole percepts from partial sensory input.
- Common fate groups elements that move together into unified perceptual objects.

## Figure-Ground

- Figure-ground segregation distinguishes objects of attention from their background context.
- Figures are perceived as having form, shape, and presence while grounds are formless and receding.
- Ambiguous figures demonstrate that figure-ground assignment is an active constructive process.
- In knowledge navigation a concept becomes figure when attended to with all related concepts as ground.

## Top-Down Processing

- Top-down processing uses prior knowledge, expectation, and context to shape sensory interpretation.
- Predictive coding proposes that the brain continuously generates predictions and updates them with prediction errors.
- Expert perception in any domain reflects refined top-down models that efficiently organize sensory input.
- TCM pulse and tongue diagnosis cultivate expert top-down perceptual models for diagnostic pattern recognition.
