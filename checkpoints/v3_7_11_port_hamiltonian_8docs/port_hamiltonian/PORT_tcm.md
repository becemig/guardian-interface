The model has five layers of increasing abstraction. Above this is the physiological layer: the organ network modeled as a bond graph with Zang-Fu organs as typed storage and dissipation elements, primary channels as transmission lines, and acupoints as junction nodes. Guardian Interface encodes all five layers in its data architecture: the physical layer in MCFSystem, the physiological layer in SomaticGraph, the energetic layer in the five element graph, the control layer in the eight vessel supervisory system, and the information layer in the telemetry and EEG channels.
