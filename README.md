# Guardian Interface

Real-time biomechanical visualization and TCM channel analysis platform

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21625068.svg)](https://doi.org/10.5281/zenodo.21625068)
[![ORCID](https://img.shields.io/badge/ORCID-0009--0007--8392--8718-brightgreen?logo=orcid)](https://orcid.org/0009-0007-8392-8718)

## Overview

Guardian Interface is an open-source real-time biomechanical visualization platform integrating inertial motion capture with TCM channel activation models. Built in Godot 4.6.2 (Mono/C#).
